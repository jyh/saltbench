## §3 · ⛔⛔ ONE CELL'S END MARKER DISAGREES WITH ITS OWN VERDICT, AND THAT IS STATED, NOT TIDIED
`ah07lzw` carries `ARM-NOT-RECEIVED` and is scored. **Both are correct and they answer different
questions.** The launcher holds on `P-DELIVERY`, which asks whether the token is in the FIRST result.
That cell's subject read its briefing (13 references to the arm file), wrote *"The receipt token has
been provided as requested"* in its first reply **while omitting it**, and emitted it on the final
turn.
⇒ ***A PROXY DIVERGES WHERE IT STOPS CARING.*** Turn-1 position proxies for *the file reached the
subject* and stops tracking it the moment the subject complies late.
⇒ The scorer therefore asks whether the subject **ever** produced the token — sound only because the
builder asserts the token occurs in **exactly one place** in the cell tree, so it can be produced only
by reading the briefing. **The launcher has not been changed mid-wave**, deliberately: a uniform
population with a stated disagreement is worth more than nine cells built two ways.
📌 **Had this gate not existed, the cell would have entered the table silently. Had it not been
repaired, a cell that scores 8/8 would have been discarded as never-briefed.** Both directions cost
data; only the second leaves no row to doubt.
